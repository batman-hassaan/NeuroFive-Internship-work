<p><strong>Focus:</strong> Setting up the Python environment, data cleaning, and data visualization.</p>
<ul>
  <li>Established a robust data science toolkit and developed the habit of "listening" to data before modeling.</li>

  <li>Created visualizations to catch data mistakes and discover underlying patterns.</li>
  <li><strong>Skills:</strong> Pandas, NumPy, Data Cleaning, Matplotlib, Seaborn.</li>
</ul>

<h3>Week 2: Supervised Learning Foundations</h3>
<p><strong>Focus:</strong> Classification and Regression modeling.</p>
<ul>
  <li><strong>Titanic Survival Prediction:</strong> Built my first classification model to predict passenger survival, transitioning EDA insights into predictive modeling.</li>
  <li><strong>House Price Prediction:</strong> Applied Linear Regression to predict continuous numerical values, learning the fundamentals of pricing and valuation forecasting.</li>
  <li><strong>Skills:</strong> Scikit-Learn, Logistic Regression, Linear Regression, Train/Test Split.</li>
</ul>

<h3>Week 3: Model Evaluation &amp; Business Applications</h3>
<p><strong>Focus:</strong> Advanced evaluation metrics, hyperparameter tuning, and Decision Trees.</p>
<ul>
  <li>Moved "beyond accuracy" to properly evaluate models using Precision, Recall, F1-Score, and ROC-AUC (crucial for imbalanced data).</li>
  <li><strong>Customer Churn Prediction:</strong> Tackled a real-world business problem prevalent in telecom, banking, and SaaS. Built a Decision Tree model to predict customer churn, balancing predictive power with interpretability for non-technical stakeholders.</li>
  <li><strong>Skills:</strong> Model Tuning, Cross-Validation, Classification Metrics, Decision Trees.</li>
</ul>

<h3>Week 4: Machine Learning Pipelines &amp; Ensemble Methods</h3>
<p><strong>Focus:</strong> Production-ready code structure and advanced modeling techniques.</p>
<ul>
  <li>Built proper ML pipelines using Scikit-learn to chain preprocessing and modeling steps securely, preventing data leakage between train and test sets.</li>
  <li>Implemented Feature Engineering to extract more value from raw data.</li>
  <li><strong>Random Forest vs. XGBoost:</strong> Explored ensemble learning by combining multiple models to create stronger, more reliable predictions.</li>
  <li><strong>Skills:</strong> Scikit-learn Pipelines, Feature Engineering, Random Forest, XGBoost, Gradient Boosting.</li>
</ul>

<h3>Week 5: Handling Imbalanced Data &amp; Model Deployment</h3>
<p><strong>Focus:</strong> Real-world data challenges and shipping a product.</p>
<ul>
  <li>Developed strategies to handle highly imbalanced datasets (e.g., fraud, disease, rare churn cases) using techniques like SMOTE, class weighting, and threshold moving.</li>
  <li><strong>Live Web App Deployment:</strong> Took a trained model out of the notebook and deployed it as a shareable, interactive web application.</li>
  <li><strong>Skills:</strong> Imbalanced Data Handling, Model Deployment, Streamlit/Web App Development.</li>
